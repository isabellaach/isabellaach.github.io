# isabellaach.github.io

Portafolio de Isabella Albarrán Chávez: https://isabellaach.github.io

Sitio propio en HTML y CSS (un solo `index.html`, en español e inglés), hecho con apoyo de Claude Code. Se publica con GitHub Actions en cada push a `master`.

- `index.html`: el sitio completo; el botón ES · EN cambia el idioma.
- `images/`: imágenes de los proyectos y la foto.
- `files/cv.pdf`: CV en PDF.
